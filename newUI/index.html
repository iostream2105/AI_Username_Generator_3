    01 / 首页结构

    首页不是一张表单，而是一张“期待地图”

    左边让用户输入线索，右边实时展示风格结果，用户能在点击前就理解产品价值。相比传统单栏表单，心理落差更小，点击意愿更高。

    02 / 结果卡片

    把“复制、收藏、分享”做成同一层动作

    结果页不再是纯文本堆叠，而是统一规格的结果卡。信息密度更可控，也更容易直接迁移成 React 组件体系。

    03 / 反馈承接

    让反馈与分享成为轻量抽屉，而不是打断式弹窗

    反馈和海报分享都用底部抽屉承接，既有层级感，也能保留结果页上下文。用户不会因为一次轻操作被硬切走。

    User Journey

    完整体验被拆成 3 个清晰阶段

    01 输入锚点

    关键词、命名模式、寓意偏好和场景捷径一起收集，减少“我不知道怎么填”的空白感。

    02 生成结果册

    中间态只保留短暂停顿和骨架反馈，让等待变成“AI 正在整理灵感”，而不是“页面好像卡了”。

    03 沉淀资产

    收藏夹、分享海报和反馈抽屉都围绕结果册展开，帮助用户把一次生成沉淀成可复用资产。
