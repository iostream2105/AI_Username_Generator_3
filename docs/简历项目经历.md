# 名有意项目经历

## 项目介绍

独立开发 AI 昵称生成产品“名有意”，面向微信昵称、小红书昵称、游戏 ID、英文社媒名等场景，支持中文、英文和中英混合三种生成模式，完成需求分析、方案设计、前后端开发、数据埋点及云端部署。

## STAR 法则

- `S/T`：针对社交平台用户昵称同质化、个性化表达不足的问题，设计覆盖微信、小红书、游戏、英文社媒等场景的 AI 昵称生成方案。`A`：规划中文、英文、中英混合三种模式，并补充场景页、推荐输入和结果解释。`R`：形成可面向多类用户场景展示的产品化方案。  

- `S/T`：为提升用户留存与传播效果，将单一生成能力扩展为完整业务闭环。`A`：基于 React + TypeScript、Express、MySQL 实现生成、收藏、反馈、分享海报和移动端状态恢复等功能。`R`：打通“生成 - 收藏 - 分享 - 反馈”链路，提升产品可用性与交付完整度。  

- `S/T`：为支撑上线运营和后续优化，建立数据分析与线上交付能力。`A`：设计埋点体系和后台看板，支持生成记录、事件日志、收藏、反馈查询及 CSV 导出，并完成 CloudBase + CloudRun 部署。`R`：项目具备线上演示、数据复盘和持续优化能力。
