# 名有意项目经历

围绕社交昵称与个人表达场景，我独立完成了 AI 网名生成产品“名有意”的需求拆解、方案设计、前后端开发与上线部署，面向移动端用户构建了一个支持中文、英文和中英混合昵称生成的完整解决方案。项目基于 React + TypeScript、Express、MySQL 与 CloudRun 搭建，接入 AI 大模型实现结构化生成，并设计了生成、收藏、反馈、分享海报、埋点分析和后台看板等业务闭环能力，可覆盖微信昵称、小红书昵称、游戏 ID、英文社媒名等多个细分场景；在项目推进中，我不仅关注功能实现，也同步从用户需求理解、场景化表达、运营数据复盘和上线可交付性角度完善方案，体现了面向客户场景做产品化落地、推动方案交付与持续优化的综合能力，较好契合销售工程师、解决方案工程师与客户经理岗位对“业务理解 + 技术沟通 + 方案落地”的要求。
