# 名有意项目经历

## 简洁项目介绍

“名有意”是一款面向移动端用户的 AI 昵称生成产品，聚焦微信昵称、小红书昵称、游戏 ID、英文社媒名等场景，支持中文、英文和中英混合三种生成模式。我独立完成了需求拆解、方案设计、前后端开发、数据埋点和云端部署，搭建了从生成、收藏、分享海报、反馈到后台分析的完整业务闭环，体现了从客户场景理解到解决方案落地的综合能力。

## STAR 法则描述

- `S`：社交平台用户在更换昵称时，常见痛点是结果模板化、缺少个性表达，且不同平台对昵称风格和使用场景差异明显。`T`：围绕“个人表达 + 多平台适配”需求，设计一套可覆盖微信、小红书、游戏、英文社媒等场景的 AI 昵称生成方案。`A`：梳理核心用户链路，规划中文、英文、中英混合三种生成模式，并补充场景页、推荐输入、结果解释等能力，降低用户输入门槛并提升场景匹配度。`R`：产品可支持多个高意图使用场景，形成更贴近真实用户需求的方案表达，而不是单一的“AI 工具展示”。  

- `S`：仅有生成能力无法支撑长期使用与传播，用户需要复制、收藏、分享和再次回访的完整体验。`T`：把单点生成能力扩展为可交付、可传播、可复访的产品闭环。`A`：基于 React + TypeScript、Express、MySQL 搭建前后端系统，完成生成接口、收藏能力、反馈机制、分享海报、移动端状态恢复等功能设计与实现。`R`：项目形成了“生成 - 收藏 - 分享 - 反馈”的完整使用闭环，提升了产品可用性，也更符合真实业务场景中的解决方案交付思路。  

- `S`：产品上线后如果缺少数据回流，就难以判断用户是否真正接受方案，也无法支持后续优化。`T`：建立面向运营和产品复盘的数据分析机制。`A`：设计埋点事件、接入生成/复制/收藏/保存海报/反馈等关键行为追踪，并开发后台管理端，支持总览看板、生成记录、事件日志、收藏记录、反馈查询和 CSV 导出。`R`：项目具备了从用户行为采集到后台复盘分析的能力，为后续优化方案、支撑业务沟通和结果复盘提供了基础。  

- `S`：要让项目具备真实交付价值，仅完成本地开发还不够，还需要解决上线部署、移动端体验和运维可用性问题。`T`：将项目部署为可访问、可演示、可扩展的线上方案。`A`：完成 CloudBase 静态托管 + CloudRun 后端部署方案设计，处理同域 API 路由、移动端优先交互、海报导出与场景页直达访问等问题，并补充部署文档与配置说明。`R`：项目已具备线上交付与演示条件，可用于展示我在方案落地、跨端体验和交付推进方面的综合能力。
