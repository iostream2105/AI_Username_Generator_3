# 名有意项目经历

## 项目概述

独立开发并上线 AI 网名生成产品“名有意”，面向微信昵称、小红书昵称、游戏 ID、英文社媒名等场景，支持中文、英文、中英混合三种生成模式，完成从需求分析、方案设计到前后端开发、数据埋点、后台看板与云端部署的完整闭环。

**技术栈：** React + TypeScript + Express + MySQL + 豆包大模型 + CloudRun

## 可直接用于简历的四点描述

1. 围绕社交平台用户“昵称同质化、缺少个人表达、难以兼顾风格与寓意”的痛点，独立完成产品需求拆解与方案设计，搭建覆盖微信、小红书、游戏、英文社媒等多场景的 AI 命名方案，并设计中文 / 英文 / 中英混合三种生成模式与结果解释机制——体现从用户场景洞察出发，将模糊需求转化为清晰解决方案并面向客户表达价值的能力

2. 独立负责产品全链路落地，基于 React + TypeScript、Express、MySQL 完成前后端开发，打通“输入关键词 -> AI 生成 -> 复制/收藏 -> 分享海报 -> 用户反馈”的业务闭环，并针对手机端重点优化输入、弹窗、返回与状态恢复体验——体现将方案真正交付为可演示、可使用、可持续迭代产品的执行与落地能力

3. 为支撑后续演示、运营与复盘，设计埋点体系和后台管理能力，支持生成记录、事件日志、收藏记录、用户反馈查询及 CSV 导出，并完成 CloudRun 部署上线，使产品具备可观测、可复盘、可快速响应需求变化的基础能力——体现方案交付后仍能持续服务客户、支撑沟通复盘与优化推进的项目经营意识

4. 基于生产环境数据库汇总数据持续验证方案效果，上线近 3 周累计获得 355 次首页曝光、310 次生成点击、307 次成功生成，生成成功率约 99%，覆盖 56 名用户，并产生 46 次分享点击与 10 条真实用户反馈，为后续功能优化和运营判断提供依据——体现以真实使用数据衡量方案效果、发现机会并推动持续优化的结果导向能力

## 备注

- 文中数据来自生产环境数据库 `mingyouyi` 的汇总统计，统计时间截至 2026-04-11，仅使用聚合指标，未使用任何用户明细信息。
